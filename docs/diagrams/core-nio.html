strand-core + strand-nio: 전송 스레드가 Endpoint를 전담

스레드 경계Endpoint는 연결마다 하나인 전송 스레드만 부른다. 호출 스레드는 예약을 먼저 확보한 뒤 명령 큐에 넣고 wakeup으로 깨운다. 인증·핸들러·알림은 SerialExecutor에서 돈다.
읽기와 쓰기TcpPassage가 읽기·쓰기 관심을 하나의 Selector로 다루고, 전송 스레드는 await으로 읽기·쓰기·시계를 한 루프에서 돌린다. 쓰기는 부분 쓰기이며 쓴 만큼만 보고한다.
선택 단계TLS 통로는 암호문을 평문으로 바꾸는 SSLEngine 층이고, TLS를 끄면 엔진이 TcpPassage를 바로 쓴다. WebSocket은 지원하지 않는다.
