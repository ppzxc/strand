# strand

Java 8 이상을 지원하는 바이트 인코딩·디코딩 라이브러리입니다.

## 상태

프로젝트 셋업 단계입니다. 구조, 빌드, 배포 방식을 확정하는 중이며 아직 코드는 없습니다.
진행 상황은 [[MAP] strand 프로젝트 셋업](https://github.com/ppzxc/strand/issues/1)에서 추적합니다.
