## Agent skills

### Issue tracker

Issues live in GitHub Issues (`ppzxc/strand`, via the `gh` CLI). Titles use fixed prefixes (`[MAP]`, `[MAP #NN / GRILLING]`, `[MAP #NN / SPEC]`, `[SPEC #NN / TICKET-N]`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context. See `docs/agents/domain.md`.
